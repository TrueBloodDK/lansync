# LANSync — этап 1: индекс файловой системы

Учебный проект системы синхронизации файлов в локальной сети.
На этом этапе реализованы полное сканирование, индекс SQLite и JSON-манифест.
Наблюдение в реальном времени и сетевой обмен пока не реализованы.

## Установка

Требуется Python 3.11 или новее. Команды выполняются из папки проекта.
На Windows вместо `python` при необходимости используйте `py -3`.

```sh
python -m venv .venv
```

Активация в PowerShell: `.\.venv\Scripts\Activate.ps1`.
Активация в Linux: `source .venv/bin/activate`.

```sh
python -m pip install -e .
lansync --help
```

Рабочий код использует только стандартную библиотеку Python.
Для установки пакета pip может потребоваться доступ к индексу пакетов.

## Использование

Windows:

```powershell
lansync scan "C:\Users\User\Documents\Shared" --state-dir "C:\Users\User\Documents\lansync-state"
```

Linux:

```sh
lansync scan "$HOME/Shared" --state-dir "$HOME/lansync-state"
```

Указанный каталог должен существовать. Повторите команду после изменения
файлов: индекс обновится, исчезнувшие объекты получат `deleted: true`.
Перемещение пока представляется удалением старого пути и появлением нового.

В папке состояния создаются `index.sqlite3` и `manifest.json`.
Экспорт можно перенаправить аргументом `--manifest /path/to/manifest.json`.
Состояние и экспорт должны находиться вне сканируемой папки.
Каждой корневой папке нужна отдельная папка состояния.

Без `--state-dir` состояние хранится в `%LOCALAPPDATA%/lansync` на Windows
или `$XDG_STATE_HOME/lansync` (по умолчанию `~/.local/state/lansync`) на Linux.
Подкаталог выбирается по хешу абсолютного пути.

Коды завершения: `0` — полное сканирование; `1` — ошибка запуска/экспорта;
`2` — есть ошибки чтения или исключённые объекты, манифест неполный.

## Формат и гарантии

Верхние поля манифеста: `schema_version`, `device_id`, `folder_id`,
`generation`, `complete`, `errors`, `skipped`, `entries`.
Пути внутри `entries` относительные, разделитель — `/`.
Файлы имеют размер, время изменения и SHA-256; каталоги — тип и время,
а размер и хеш равны `null`. Пустые каталоги учитываются.

Хеширование выполняется блоками по 1 МиБ. Параметры файла проверяются
до и после чтения. При обнаруженном изменении файл отмечается ошибкой;
повторная попытка пока выполняется следующим запуском команды.
Каждое сканирование заново хеширует все доступные файлы.

SQLite обновляется транзакционно. JSON записывается во временный файл
и заменяет предыдущий экспорт после завершения записи. Сбой экспорта
не откатывает уже сохранённый индекс; повторите команду.

При любой ошибке сканирования новые удаления не фиксируются во всём дереве.
Старые записи недоступных файлов остаются в индексе, но `complete: false`
и `errors` сообщают, что это не подтверждённое текущее состояние.
Ссылки, Windows reparse points и специальные файлы исключаются;
предыдущие записи под исключёнными путями сохраняются без отметки удаления.

`generation` — номер локального сканирования, не серверная ревизия.
Идентификаторы сейчас относятся к локальному индексу; привязка нескольких
устройств к общему каталогу появится на этапе сетевого протокола.

## Тесты без дополнительных зависимостей

После установки проекта:

```sh
python -m unittest discover -s tests -v
```

Без установки, PowerShell:

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python -m lansync --help
```

Linux: `PYTHONPATH=src python -m unittest discover -s tests -v`.
Тесты также совместимы с pytest (`pip install -e ".[dev]"`).

## Ограничения и следующие этапы

Это снимок результатов обхода, а не атомарный снимок файловой системы.
Каталог, который меняется во время обхода, требует повторной сверки.
Проверка параметров файла снижает риск гонки, но не заменяет снимки ОС.
Не запускайте несколько сканирований одной папки состояния одновременно.
Индекс содержит всё дерево в памяти; потоковым является чтение содержимого.

Дальнейшие этапы: очередь событий watchdog, сверочные обходы, исключения,
проверка переносимости имён, протокол ревизий, передача файлов и конфликты.
Сетевой защиты пока нет, поскольку сетевые компоненты отсутствуют.
Поддержку Linux необходимо подтвердить запуском тестов на Linux.
