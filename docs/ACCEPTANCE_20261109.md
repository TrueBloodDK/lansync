Рабочие репозитории test1 (192.168.0.108) и test2 (192.168.0.109) обновлены
через git pull --ff-only до 96970eb. На каждой ВМ прошли все 121 тест.

SIGTERM и перезапуск клиента с прежним состоянием.

межмашинный или межплатформенный прогон. После испытаний процессы остановлены;
постоянные службы и firewall не менялись. Тестовые проекты оставлены в
~/lansync-lifecycle-20261109, включая verification.json и журналы.

повторного использования существующего output без изменения прежнего отчёта.
