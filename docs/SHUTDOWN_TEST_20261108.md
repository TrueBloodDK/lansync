# Проверка штатной остановки, 8 ноября 2026

Поддерживаемая схема: сервер Linux, клиенты Windows/Linux. Windows-сервер
исключён из приёмки по уточнённым требованиям; старые отчёты сохранены как история.

Оба рабочих репозитория ВМ обновлены через git pull --ff-only до 058157c:
на test1 (192.168.0.108) и test2 (192.168.0.109) прошли все 117 тестов,
включая сохранение двух версий конфликта.

Изменения обработки SIGTERM проверены отдельно: архив исходников с рабочими
изменениями распакован во временные каталоги каждой ВМ, запущен с PYTHONPATH=src
и Python из существующего venv. Рабочие checkout не изменялись.

Результаты окончательного прогона:

- Windows: 121 тест, 114 успешно, 7 POSIX-проверок пропущены.
- Linux test1: все 121 тест прошли.
- Linux test2: все 121 тест прошли.

Новые проверки на Linux запускают настоящие CLI-процессы watch, status --watch
и sync --watch --local-events. После готовности им отправляется SIGTERM:
ожидание с интервалом 300 секунд завершается менее чем за 5 секунд, код выхода 0.
Для sync проверены состояние stopped и отсутствие sync.lock после остановки
при повторных попытках подключения к недоступному loopback-порту.

Отдельная проверка отправляет сигнал внутри подменённого прохода синхронизации:
проход завершается, новый не начинается, блокировка освобождается, отчёт сохраняется.
Также проверены повторный сигнал, восстановление предыдущего обработчика при ошибке
и отсутствие изменения обработчиков при вызове из рабочего потока.

Это проверка штатной остановки. SIGKILL, отключение питания, перезагрузка,
длительная передача в момент остановки и постоянный автозапуск здесь не проверялись.
