## Подготовленная проверка входа Windows

Для текущего пользователя создана запись `LANSyncDesktop` в HKCU Run через
код диалога автозапуска. Предыдущая запись отсутствовала; настройки до изменения
сохранены рядом с тестовым проектом. Команда длиной 211 символов проверена
повторным чтением реестра. Запускается готовая dev10 с явным `--config` и
`--start-sync`; окно остаётся видимым.

Проект находится в `outputs/win-login/project` рядом с репозиторием. Перед
передачей управления пользователю GUI запущен в Windows и получил свежий synced.
Это проверка регистрации и запуска, **не реального входа Windows**.

Для завершения:

1. Сохранить работу в Windows. Штатно выключить обе ВМ через Linux, чтобы выход
   из Windows не оборвал их через VirtualBox.
2. Оставить Windows LANSync работающим и выйти из учётной записи Windows.
3. Войти снова. LANSync должен открыться автоматически. Пока сервер выключен,
   ожидается повтор подключения.
4. Запустить ВМ и дождаться «Синхронизировано». Проверить новый PID и время
   успешного прохода относительно текущего входа, а не только сохранённый статус.

Выход из Windows закрывает текущую сессию приложений, поэтому этот шаг выполняет
пользователь. Для отключения тестового автозапуска используется «Автозапуск…»
в GUI; не перемещайте приложение и проект до завершения проверки.
