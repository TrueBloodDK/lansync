# Выпуск GUI 0.2.0

Переносимый клиент Windows/Linux с мастером проекта, планом, синхронизацией,
конфликтами, recovery, журналом, треем и автозапуском. Сервер работает на Linux;
протокол совместим с сервером 0.1.0. Python переносимому клиенту не требуется.

Распакуйте архив целиком и сохраните `_internal` рядом с исполняемым файлом.
Проект храните вне каталога приложения. Перед обновлением остановите клиент,
закройте его, распакуйте новую сборку отдельно и откройте прежний project.toml.
После смены пути обновите автозапуск. Работающие приложения на стенде автоматически
не заменялись, опубликованных GitHub Releases и тегов эта проверка не создаёт.

- [Первый запуск](GUI_QUICKSTART.md).
- [Демонстрация](GUI_DEMO.md).
- [Приёмка Windows](GUI_ACCEPTANCE_20261122.md).
- [Приёмка Linux](GUI_ACCEPTANCE_LINUX.md).
- [Контрольные суммы и проверки окончательных архивов](evidence/release-0.2.0.json).

Оба окончательных бинарника прошли offline smoke и HTTPS-синхронизацию с сервером
стенда. SHA-256 архивов проверены после сборки/скачивания. Ручная приёмка виджетов
выполнялась на предшествующих dev-сборках; в 0.2.0 алгоритмы GUI не менялись.

Linux-сборка проверена на CachyOS x86_64 (glibc 2.44); совместимость с более старыми
дистрибутивами этим не подтверждается. После аварии старые блокировки и pending
требуют проверки. Нельзя одновременно запускать два клиента для одного состояния.
