Для повторения: создайте отдельные пустые shared/state на сервере и клиенте,
подготовьте credentials, запустите serve --allow-write на Linux. На Windows
выполните doctor, затем sync. Последовательно создайте русское имя и пустые
объекты на сервере, двоичный файл на клиенте; сравните содержимое и SHA-256.
Изменяйте файлы только на одной стороне за проход. После установления общей
версии измените один путь на обоих узлах, выполните sync (код 2), затем resolve
--choose remote. Перед применением удаления проверьте sync --dry-run --json.
Завершите recovery verify на обоих узлах. Сохраняйте stdout, stderr и коды возврата.
