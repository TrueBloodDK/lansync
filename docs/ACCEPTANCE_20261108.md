# Приёмочный прогон 8 ноября 2026

Версия c5c7b4a. Обе CachyOS ВМ обновлены из GitHub через git pull --ff-only.
На каждой прошли все 113 unittest без пропусков.

## Серия изменений в непрерывном режиме

На test2 два отдельных процесса Linux server/client работали по HTTPS loopback.
40 шагов за 59.375 секунды: запись попеременно с двух сторон, 8 удалений,
проверка содержимого после каждого шага, сравнение финальных SHA-256.
Все проверки прошли. После SIGINT sync.lock отсутствует.
RSS сервера: начало 63100 КиБ, конец/максимум 63628 КиБ.
RSS клиента: начало 60692 КиБ, конец/максимум 62224 КиБ.
Это короткий прогон, не доказательство отсутствия утечек и не нагрузочный тест.

## Фоновый запуск Linux

На test2 сервер и клиент запущены как две временные пользовательские службы
systemd через systemd-run --user. Проверен active у обеих, передача нового файла,
затем штатная остановка с SIGINT и отсутствие sync.lock. Временные службы
остановлены; enable/постоянный автозапуск не настраивались. Перезагрузка и запуск
при новом входе пользователя не проверялись.

## Незавершённый межплатформенный сценарий

Windows-сервер успешно слушал 192.168.0.102:8876, но TCP-подключение из test1
192.168.0.108 снова завершилось тайм-аутом. Сценарий Windows-сервер/Linux-клиент
не пройден. Сервер остановлен. Изменений Windows Firewall в этом прогоне не было.
После уточнения требований серверная роль Windows исключена из области поддержки;
продолжение этого сценария не требуется и не блокирует выпуск.
Ранее проверенный Linux-сервер/Windows-клиент остаётся отдельным результатом.

Аварийные испытания по просьбе пользователя отложены. Пользовательские папки
не использовались. Тестовые данные Linux оставлены в ~/lansync-soak-20261108.
